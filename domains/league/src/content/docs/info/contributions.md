---
title: Contributions
description: How to help the league grow.
---

Ranked Leagues is a community-driven project! If you'd like to help out with the event, get the `event-planner` role in the Discord server and let us know what you could help with in the `#ranked-league-planning` channel. We're always looking for new people to help out with the event.

If you'd like to help out with the website, check out the [GitHub repository](https://github.com/Notava1ble/mscl-website).
